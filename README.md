# 🎯 The Problem

Students and early-career professionals often struggle with:

- Finding opportunities that actually match their skills
- Knowing which internships, jobs, hackathons and fellowships are relevant
- Understanding why an opportunity is a good match
- Identifying missing skills before applying
- Tracking applications and deadlines
- Knowing what to learn next

The result is **information overload, missed opportunities and unclear career direction.**

---

# 💡 Our Solution

OpportunityOS brings opportunity discovery, skill intelligence and career planning into one unified platform.

Instead of asking:

> **"What opportunities are available?"**

OpportunityOS asks:

> **"Which opportunities are right for YOU — and what should you do next?"**

Our goal is simple:

**Less searching. Better matching. Smarter career decisions.**

# 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Ayushi-Pande/Opportunity-os.git
```

### 2. Navigate to the project

```bash
cd Opportunity-os
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Open the local URL shown in your terminal, usually:

```text
http://localhost:5173
```

---

# 🔐 Environment Variables

Create a `.env` file locally when environment variables are required.

Example:

```env
VITE_API_URL=your_api_url
```

> ⚠️ Never commit your real `.env` file or API keys to GitHub.

Use `.env.example` to share required variable names safely.
